# Publicação no GitHub Pages

**Estado:** publicada e acessível. Nas configurações do repositório, a fonte salva é a branch `main`, pasta `/docs`, com HTTPS obrigatório.

- **Endereço público:** [https://eu-vinicosta.github.io/infosec-portfolio/](https://eu-vinicosta.github.io/infosec-portfolio/)
- **Arquivo inicial:** `docs/index.html`
- **Domínio personalizado:** não configurado nem necessário; o endereço `github.io` é usado.

## Atualizações futuras

Alterações integradas à pasta `docs/` da branch `main` são a fonte do site. Para acompanhar uma publicação, abra a aba **Actions** do repositório e confira o workflow do GitHub Pages. O endereço também aparece em **Settings → Pages**.

Sites do GitHub Pages são públicos. A documentação oficial explica a publicação a partir de uma branch e da pasta `/docs`: [Configuring a publishing source for your GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
