# Publicação no GitHub Pages

O site estático está em `docs/` e não usa dependências externas. O Pages ainda não foi habilitado; nenhuma publicação foi feita.

## Depois da revisão e merge da PR

1. Abra o repositório `eu-vinicosta/infosec-portfolio` no GitHub.
2. Acesse **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione `main` como branch e `/docs` como pasta.
5. Salve e acompanhe o workflow de publicação na aba **Actions**.
6. Depois que o build terminar, confirme a URL mostrada em **Settings → Pages**. O endereço esperado para este repositório é `https://eu-vinicosta.github.io/infosec-portfolio/`.

Não ative o Pages antes da revisão humana da PR e de confirmar que os arquivos publicados contêm somente material aprovado. Sites do GitHub Pages são públicos. A documentação oficial descreve a publicação a partir de uma branch e da pasta `/docs`: [Configuring a publishing source for your GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
